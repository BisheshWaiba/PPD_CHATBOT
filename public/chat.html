History

Sutkeri is not a substitute for professional medical care.

Tips

  • Reply with a number when Sutkeri lists options.
  • Type symptoms to check how you're feeling.
  • After the first few questions, type take EPDS for the 10-question screening and a printable results page.
  • Sutkeri only answers questions about postpartum wellbeing. For anything else, type menu to see what it can help with.
  • Type new to start a new conversation.

Need help now?
